# Daily

1. Close yesterday: for each open commitment, ask what happened and write the result. Each miss gets a `MISS` line in `LEDGER.md`.
2. Pick today's commitments with the owner: at most three, each small enough to start right now, each with a time and a proof.
3. Write them under `## Today (YYYY-MM-DD)` in `STATE.md`.
4. Book the timed ones on the calendar with a `<house>` block.
5. Ask the owner to start the first one before the session ends.
